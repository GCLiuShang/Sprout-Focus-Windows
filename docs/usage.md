# Usage

## 基本逻辑

开始专注后，Sprout 每 350ms 检查一次前台窗口。**命中任意一条放行规则就放行**，否则该窗口会被立刻最小化，并由 Windows 决定接下来聚焦哪个窗口；每次拦截计入违规记录。

浏览器里的具体内容不在 Sprout 的职责范围内，交给浏览器插件（例如 `网费很贵 / BlockSite`）处理。Sprout 只做桌面窗口层面的拦截。

## 放行规则：精准匹配 / 模糊匹配

规则以「规则集」为单位组织，每个规则集可单独**启用/停用**，只有已启用的规则集参与本轮的放行判断。精准规则集与模糊规则集相互独立。

### 精准匹配（窗口 / 进程）

- **窗口**：匹配该窗口（标题 + 进程路径完全相等），也可用当前会话内的窗口句柄临时加速。
- **进程**：匹配该进程的所有窗口（按进程路径或进程名完全相等）。

操作方式：

1. 把目标窗口切到前台，回到「编辑规则 → 精准匹配」。
2. 候选窗口卡会实时显示上一个外部窗口；选择类型（窗口 / 进程）。
3. 选择「加入规则集」的目标规则集，点「加入规则集」。

也可以「手动添加进程」：输入进程名（如 `Code.exe`）或完整路径，按精确匹配处理。

适合需要长期保留的工具，如 VS Code、终端、PDF 阅读器。精准匹配粒度更明确，但窗口标题一旦变化，窗口类型条目可能失效，此时改用进程类型或模糊匹配。

### 模糊匹配（短语）

用**短语**描述特征：命中窗口标题 / 进程名 / 路径任意一处即放行。短语默认按**字面量包含**（忽略大小写）匹配；勾选「高级正则」后按正则表达式匹配（非法正则会被拒绝）。

操作方式：

- 在某个模糊规则集的输入框里输入短语并回车即可添加；点短语上的「文本/正则」徽标可切换模式；点 × 删除。
- 「从窗口添加关键词」面板会列出当前打开的窗口，可一键把窗口的进程名或标题片段加入某个模糊规则集。

适合一类经常用的内容。**关键词不要太短**：`Code`、`AI` 这类词会命中大量无关窗口，建议用更具体的词（如 `Visual Studio`）。

一套可直接使用的模糊规则集示例：

```
Programming: Visual Studio Code|PyCharm|WebStorm|vim|Spyder|Cursor
AI: WindowsTerminal|PowerShell|cmd|Claude|Codex|Copilot|ChatGPT|Gemini
Notes: Obsidian|Typora|OneNote|Notion|Logseq
Paper: Zotero|Acrobat|SumatraPDF|论文
Office: Word|Excel|PowerPoint|WPS
Creative: Photoshop|GIMP|Inkscape|Premiere|剪映|Figma
Comms: 微信|WeChat|QQ|Slack|Teams|Discord|Telegram|飞书|Zoom
```

## 计时模式

- **倒计时**：设置时长，到点自动完成，并触发 Windows 系统通知与提示音。
- **正计时**：从 00:00 开始累加，只能手动结束。

## 管理员级窗口拦截

在设置中开启「拦截以管理员身份运行的窗口」后：

- **每次开始专注都需要一次 UAC 授权**（由独立的提权 helper 执行最小化）。
- 若在 UAC 中点击「否」，**本轮不会启动**，会给出明确提示；下次点击开始会重新请求授权。
- 未开启时，以管理员身份运行的窗口无法被最小化，也不会弹出 UAC。

设置里另有一项「点击『开始专注』后不再显示提示窗口」：不勾选时每次开始都会先弹提示由你临场决定；勾选后不再提示，是否拦截由「拦截以管理员身份运行的窗口」开关决定。

## 退出保护

会话中点击「结束专注」会触发打字验证，防止冲动退出。难度可调：

- 简单：固定短语
- 中等：随机符号串
- 困难：生僻汉字

## 系统安全白名单

建议常开。资源管理器、任务栏、开始菜单、锁屏、UAC、截图/贴图工具（含 Snipaste）等系统界面靠它兜底，关掉容易误伤。极端情况下若系统界面状态异常，可在任务管理器中重启 Windows 资源管理器。

## 设置项说明

- **历史记录目录**：每轮专注结束生成的 Markdown 写到这里。
- **自动写 Markdown 历史记录**：开启后每轮结束自动落一份记录。
- **启用系统安全白名单**：见上。
- **拦截以管理员身份运行的窗口**：见上。
- **退出验证难度**：见上。

## 专注态

开始专注后，左侧应用栏与规则摘要会隐藏，界面只保留计时器、当前上下文与违规时间线，保持简洁。结束或完成会话后恢复。

## 历史记录

每轮专注结束后自动生成 Markdown，记录开始 / 结束时间、计划与实际时长、违规次数、本轮规则集配置，以及完整的违规时间线。文件名形如 `YYYY-MM-DD.md`，存储在历史记录目录下。
